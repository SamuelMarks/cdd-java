# Usage
Detailed usage of the tool:
`make run -- --help`
- `cdd-java from_arazzo to_sdk -i <arazzo.json> [-o <dir>] [--tests]`
- `cdd-java from_arazzo to_sdk_cli -i <arazzo.json> [-o <dir>] [--tests]`
- `cdd-java from_arazzo to_server -i <arazzo.json> [-o <dir>]`
- `cdd-java to_arazzo -i <path/to/code> [-o <arazzo.json>]`
See README.md for more info.
